# Password Security Awareness

1. **Use unique passwords.** A password reused across multiple services allows one compromise to affect more than one account.
2. **Prefer length.** Longer passwords generally give attackers a larger search space; for a single-factor password, current NIST guidance sets a 15-character minimum.
3. **Avoid predictable context.** Names, dates, organization names and similar information can be guessed.
4. **Avoid common passwords.** Blocklists help prevent highly guessable choices. NIST SP 800-63B-4 requires comparison against commonly used, expected or compromised values.
5. **Do not reuse passwords.** Credential stuffing relies on previously obtained username/password pairs.
6. **Use a password manager.** It can generate and store unique credentials and reduce reuse.
7. **Enable MFA.** Passwords are not the only authentication layer; MFA reduces reliance on the password alone. OWASP identifies MFA as a core defense against credential stuffing and password spraying.
8. **Never share passwords.** Support staff should not need the user's password.
9. **Watch for phishing.** A long password cannot stop a user from typing it into a fake site.
10. **Change passwords on evidence of compromise.** Modern guidance discourages arbitrary periodic changes and supports event-driven changes when compromise is known or suspected.
