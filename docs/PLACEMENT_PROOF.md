## LinkedIn project description

Built a defensive cybersecurity project, **Password Strength Analyzer & Security Suggestion Tool**, with FastAPI and React. The application analyzes password length, character diversity, common-password matches, dictionary words, keyboard patterns, sequences, repetition, predictable structures, optional personal context, and entropy concepts, then provides specific security recommendations.

A key engineering goal was privacy-by-design: password values are processed transiently and are not stored in the analytics database, returned by the API, placed in URLs, or persisted in browser storage. I also implemented a secure password generator using Python `secrets`, a separate Argon2id hashing demonstration, configurable password-policy guidance, aggregate analytics, and automated security/privacy tests.
